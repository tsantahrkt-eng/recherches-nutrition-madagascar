Guide de lecture des catégories

Cette page explique les champs utilisés dans l’inventaire afin de faciliter la lecture des fiches par les membres, partenaires et institutions.

Champs stratégiques renseignés par MIKASA

Ces informations sont affichées lorsqu’elles existent dans la base. Elles ne sont pas ouvertes à la saisie publique.

Axe PNN/PNAMN
Domaine stratégique auquel la recherche est rattachée.
Axe secondaire
Rattachement complémentaire lorsque la recherche couvre plusieurs dimensions.
Lien direct
La recherche porte explicitement sur un résultat, une intervention, une population ou un problème nutritionnel.
Lien indirect
La recherche agit sur un déterminant amont : système alimentaire, produit, filière, transformation, qualité sanitaire ou ressources alimentaires.
Potentiel d’action
Usage possible de la recherche : formation, sensibilisation, amélioration de produit, programme public, contrôle qualité ou recherche complémentaire.

Champs saisis ou corrigés dans les fiches

Les contributeurs habilités peuvent compléter les informations descriptives, les liens documentaires et les éléments de méthode.

Type de recherche
Nature principale du travail : diagnostic, formulation, analyse de laboratoire, étude de filière, politique, etc.
Population cible
Publics concernés par la recherche. Plusieurs populations peuvent être sélectionnées.
Méthodologie
Méthodes mobilisées. Plusieurs méthodes peuvent être indiquées pour une même fiche.
Région
Une ou plusieurs régions de recherche peuvent être choisies à partir de la liste des 24 régions.

Valeurs disponibles dans la base

Les listes ci-dessous se mettent à jour à partir des données chargées.

Qualité de lecture

Les valeurs manifestement techniques ou non informatives ne sont pas affichées comme contenu de fiche. Les cellules vides apparaissent comme non renseignées.

Les corrections réalisées dans l’interface peuvent être exportées en Excel pour consolidation par MIKASA.

Saisie ou correction d’une fiche

Cette zone permet d’ajouter une fiche ou de corriger les informations descriptives. Les champs stratégiques PNN/PNAMN sont affichés dans les fiches lorsqu’ils existent, mais ne sont pas proposés à la saisie.

Les modifications sont enregistrées dans le navigateur courant. Utiliser ensuite l’export Excel pour transmettre la base consolidée.
